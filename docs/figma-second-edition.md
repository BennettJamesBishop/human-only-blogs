## Direction and scope

Copy/paste remains banned in the writing area. Internal passage movement, cuttings, history, and recovery support revision. Six mobile views cover reading, writing, library, profile, preferences, and history. Email-link sign-in is a proposal; account architecture remains undecided.

Main navigation is linked within the second-edition page. Links to first-edition screens open design nodes by URL because Figma cannot navigate to frames on another page. State-changing controls are visual mockups, not working services. The save/recovery board presents separate state specimens.

New screens were visually reviewed and bounds checked for overflowing content. Shared variables, text styles, and button instances preserve the original identity. No functional editor or browser implementation is implied. Fixture names and prose are illustrative AI-generated content.

Pricing, finalized legal text, moderation workflows, media creation, and account architecture remain outside this pass.
